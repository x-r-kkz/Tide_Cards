# Tide: Card Game

## WARNING
Game contains sensitive topics like suicide and self-harm.

## Description
A card game based off of my story, Tide. This is made to have a somewhat accurate perspective of the main character and how mental health may work for some.

**Objective:** Get to 100 sanity to save Mili (you) using combinations of different cards.

## How to Run
- Open the *game.py* file by double-clicking
- Run by pressing the arrow/triangle play button

## How to Play
- After running the game, answer the first few questions about viewing instructions and previous gameplay
- Pick a number from 1 to 5, the number you choose corresponds to the order of the cards shown on screen within the brackets (*[ ]*)
- Certain events require further inputs. When these are met, just follow what is asked.
- The cycle loops until you reach 1 of 3 endings (no more cards, death, survival).
